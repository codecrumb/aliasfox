# Security policy

AliasFox is a personal, unofficial, best-effort project. There is no guarantee of a response
time, a fix, or availability, and no bounty is offered.

## Reporting a vulnerability

Please report privately, not in a public issue:

1. Use GitHub private vulnerability reporting: open the repository's "Security" tab, then
   "Report a vulnerability" (https://github.com/codecrumb/aliasfox).
2. Or write to the contact address shown on the privacy page of the running service. The operator
   sets that address through the `CONTACT_EMAIL` environment variable; it is not written in this
   repository.

## Ground rules

- Test only against your own deployment and your own account.
- Do not access, change or keep other users' data.
- Do not run denial-of-service or load tests.
- No legal safe-harbour is promised beyond this request; there is no guarantee of any kind.

## Scope

In scope: the code in this repository. Out of scope: Apple's services (iCloud), and the Neon and
Render platforms. Report problems in those to their owners.

Reports are read when time allows. There is no guarantee of acknowledgement, a fix, or credit.
